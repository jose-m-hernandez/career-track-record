# Support

To ask a question, report a bug or suggest a change, open an issue on this
repository and pick the template that fits. Say which version you ran
(`track-record --version`), what you ran, and what it printed, using invented
data in place of your own records.

There is no support service and no promised reply time. This is a small project
and replies come when they can.

For a security problem, do not open an issue: see [SECURITY.md](SECURITY.md).

Pull requests from outside contributors are not being accepted yet:
see [CONTRIBUTING.md](CONTRIBUTING.md).
