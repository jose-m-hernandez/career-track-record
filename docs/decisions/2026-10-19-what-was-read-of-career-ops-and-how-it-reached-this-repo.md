# What was read of career-ops, and how it reached this repository

Date: 2026-10-19

## The rule

> **This project is independently written and contains no career-ops code.
> One read of career-ops's source took place before any code here was written.
> Its only output allowed into this project's work was a functional
> description, in the reviewer's own words. No code, identifiers, prompt or
> instruction text, templates or file layouts beyond career-ops's public
> documentation crossed. Public copy describes the project as "independently
> written; contains no career-ops code" and makes no stronger claim about its
> origin.**

## What was read

- **Repository:** `career-ops-hq/career-ops`, branch `main`, at commit
  `ca5e70b9321daf4765f5143a4aa4d2d135f0d397`. That was the latest commit at
  the time of the read; it is dated 2026-10-19T20:57:29Z, and nothing was
  committed after it during the read.
- **When:** the evening of 2026-10-19 (Pacific time).
- **Who:** a separate, read-only reader with no write access. It fetched
  individual files by exact path and ran nothing. It worked under the
  direction of this project's technical lead, who saw only its functional
  report and released only a reviewed description. The reader was then
  discarded. The project owner did not read the source.
- **What:** about 47 files, by category: tests, the plugin engine and its
  network guard, a plugin audit script, one bundled plugin, six core scripts, a
  provenance checker, the web-request helper, two docs pages, and two agent
  instruction files.
- **Before that:** the README, the documentation pages it links, and issue
  titles, each read with code blocks removed.

## Why

A competing tool's behaviour is fair to learn from; its expression is not ours
to copy. Recording what was read, at which commit, under which licence and
through which channel lets anyone check that nothing crossed.

The cost: once the read happened, a stronger claim about how the code was
written would be contestable, so the project makes only the one above.
